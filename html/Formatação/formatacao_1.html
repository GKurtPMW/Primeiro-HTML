Explorando a Formatação Web

Um guia visual de longo formato para praticar a tag P, imagens e tipografia.

A web não é feita apenas de sistemas complexos e animações mirabolantes. Grande parte da internet, como blogs, portais de notícias e wikis, existe apenas para entregar informações de forma legível. Para isso, dominar a formatação de texto é essencial.

Elementos de Lista para Organização

Textos longos podem ser cansativos se não forem quebrados. Listas ajudam muito nisso. O que você pode treinar alterando este código:

  • Mudar o line-height no body para ver como as linhas ficam mais espremidas ou distantes.
  • Mudar o max-width da classe .artigo-container de 750px para 1000px ou 500px para ver a coluna encolhendo.
  • Trocar a font-family do body de 'Georgia' para 'Verdana' ou 'Tahoma'.
  • Brincar com a espessura da linha da esquerda no bloco de citação (blockquote).
