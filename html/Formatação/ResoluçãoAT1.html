O que é CSS?

CSS (Cascading Style Sheets, ou Folhas de Estilo em Cascata) é a linguagem usada para estilizar e dar aparência a um documento HTML. Enquanto o HTML define a estrutura e o conteúdo (o esqueleto), o CSS define as cores, fontes, layout e animações (a pele e as roupas).

Foi desenvolvido por Håkon Wium Lie em 1994, com Tim Berners-Lee também envolvido em sua adoção. A ideia era separar a apresentação da estrutura.

Sintaxe Básica de CSS

O seletor (`p`) diz qual elemento HTML estilizar. A propriedade (`color`) diz o que mudar. O valor (`red`) diz como mudar.

Unidades de Medida CSS

UnidadeDescriçãoExemplo
pxPixels: Uma unidade absoluta de tamanho fixo.`font-size: 16px;`
emRelativa ao tamanho da fonte do elemento pai.`padding: 1em;`
%Porcentagem: Relativa ao elemento contêiner.`width: 50%;`
vh/vwViewport Height/Width: Porcentagem da tela.`height: 100vh;`
